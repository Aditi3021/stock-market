# stock-market
This project focuses on analyzing the stock market performance of major tech companies — Apple, Microsoft, Netflix, and Google — over the past one month. The goal is to explore stock price movements, calculate moving averages, measure volatility, and conduct correlation analysis to understand the relationships between the stock prices of these companies. The analysis is visualized using PowerBI to generate insightful dashboards for better decision-making.

Project Overview
The objective of this project is to analyze and compare the stock performance of four major tech companies. The following tasks are covered:

Trend Analysis: Visualizing the stock price trends over time for each company.
Moving Averages: Calculating and displaying moving averages to smooth out short-term fluctuations.
Volatility Analysis: Measuring stock price volatility using standard deviation.
Correlation Analysis: Comparing the stock prices of Apple, Microsoft, Netflix, and Google to identify potential correlations.
Dashboard Creation: Combining various visualizations into an interactive Power BI dashboard to provide a comprehensive view of the data.
Data Collection
The data used in this project includes historical stock price data for Apple, Microsoft, Netflix, and Google. The data was collected via Yahoo Finance API using the yfinance library, which provides easy access to historical stock data for various companies.

Project Steps
Define the Scope and Objective: Identified the market (stock prices) to analyze, and defined objectives like identifying trends, calculating moving averages, and conducting correlation analysis.
Data Collection: Gathered historical stock data for the selected companies.
Data Preparation: Cleaned and preprocessed the data to handle missing values and ensure data integrity.
Visualization: Used Power BI to create a series of visualizations:
Line charts for stock price trends.
Dual-axis charts for comparing stock prices and trading volumes.
Heat maps to visualize price movement across companies.
Correlation analysis using scatter plots.
Dashboard Creation: Combined the individual visualizations into an interactive Tableau dashboard for a cohesive analysis.
Insight and Annotation: Added text boxes and annotations to highlight key trends, insights, and anomalies.

Key Features
Stock Price Trend Analysis: Displays stock price trends for Apple, Microsoft, Netflix, and Google.
Moving Averages: Calculates and visualizes moving averages for each company to smooth out short-term price fluctuations.
Volatility: Measures the volatility of stock prices and provides insights into market stability.
Correlation Analysis: Analyzes the correlation between stock prices of the four companies to identify potential relationships.
Interactive Dashboard: Combines all visualizations into an interactive dashboard, allowing users to filter data by company or date range.


Technologies Used
Power BI: For creating interactive data visualizations and dashboards.
Python: Used the yfinance library to download stock data for the companies.

Conclusion
This project helps in understanding stock price dynamics and provides a platform for comparing the performance of different companies in the stock market. By analyzing trends, calculating moving averages, measuring volatility, and conducting correlation analysis, this project demonstrates how data visualization tools like Power BI can be used to derive actionable insights from financial data.
